# Amigo Pet - Fase 2

Projeto acadêmico de petshop desenvolvido a partir da versão da Fase 1.

## Estrutura dos arquivos
- `index.html`: estrutura da página, produtos, serviços, carrossel e formulário.
- `css/style.css`: estilos próprios, layout responsivo e foco visível.
- `js/script.js`: validação do formulário, máscaras de CPF/telefone, seleção de horários e atualização do ano.
- `ajuda.txt`: instruções de uso e descrição das funcionalidades.

## Tecnologias utilizadas
- HTML5 semântico.
- CSS3.
- Bootstrap 5.3.3 (via CDN), incluindo componentes responsivos e carrossel.
- JavaScript.

## Como executar
Abra `index.html` em um navegador com conexão à internet para carregar o Bootstrap e as imagens externas.

## Publicação
Envie todos os arquivos e pastas deste projeto ao repositório GitHub. Mantenha a estrutura de pastas. Em seguida, habilite ou atualize o GitHub Pages nas configurações do repositório, usando a branch principal e a pasta raiz.

## Funcionalidades da Fase 2
- Carrossel de imagens Bootstrap.
- Layout responsivo para computadores e dispositivos móveis.
- Cadastro de cliente e pet.
- Escolha de banho, tosa ou banho e tosa.
- Escolha entre tele-busca e entrega do pet no local.
- Seleção de data e horário de atendimento.
- Validação de campos obrigatórios e máscaras simples.
- Acessibilidade com textos alternativos, rótulos, link para pular ao conteúdo e foco visível.

## Limitação
O formulário é demonstrativo: a validação e a mensagem de confirmação ocorrem no navegador. Nenhum dado é transmitido ou armazenado e o agendamento não é confirmado por um servidor.
