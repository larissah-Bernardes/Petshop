# Amigo Pet

Projeto acadêmico de petshop - Fase 1.

## Arquivos
- `index.html`: página principal do site.
- `ajuda.txt`: instruções de navegação e descrição do conteúdo.

## Como visualizar
Abra `index.html` em um navegador. Para publicar, envie os arquivos ao repositório
GitHub e habilite o GitHub Pages nas configurações.

## Escopo da Fase 1
Página desenvolvida em HTML, sem CSS, Bootstrap ou JavaScript.
